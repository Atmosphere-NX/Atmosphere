# AGENTS.md

## AI-Generated Code Policy

**AI-generated code is strictly prohibited in this repository.**

This includes but is not limited to:

- Code generated by large language models (LLMs) such as ChatGPT, Claude, Gemini, Copilot, Codeium, or any similar tools
- Code produced by AI code completion or suggestion tools
- Code that has been significantly modified or adapted from AI-generated output
- Patches, commits, or pull requests that contain AI-generated code in any form

### Why

This project is a custom firmware for the Nintendo Switch that requires precise, auditable, and human-written code. AI-generated code introduces unacceptable risks including:

- Potential security vulnerabilities that are difficult to detect through review
- Licensing ambiguity (AI models may reproduce copyrighted code)
- Lack of true understanding of the hardware-specific constraints this project operates under
- Inability to properly attribute authorship

### Enforcement

All pull requests will be reviewed for signs of AI-generated code. Submissions containing AI-generated code will be rejected.

Contributors are expected to write their own code. If you are unable to write the code yourself, this project may not be the right place for your contribution.

### Alternatives

If you need help understanding the codebase or Nintendo Switch hardware, please:

- Read the existing documentation in the `docs/` directory
- Consult the [switchbrew wiki](http://switchbrew.org)
- Ask questions in the project's Discord channel
- Review existing code for patterns and conventions
